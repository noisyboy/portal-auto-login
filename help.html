Portal Auto-Login // Docs

An automated, multi-profile captive portal bypass and authentication engine.

1. Core Mechanics

The extension listens for network anomalies—specifically, when a standard HTTP request (e.g., to neverssl.com) is hijacked and redirected to a local gateway. Once detected, the extension evaluates the target domain and executes the corresponding profile.

2. Standard Mode (Universal DOM Parser)

If Raw Request Override is disabled, the engine injects a content script into the portal page.

  • It dynamically maps visible DOM elements, prioritizing type="password" and its preceding text field.
  • It dispatches native input and change events to bypass client-side JavaScript validation.
  • It forces a physical .click() on the submit button to ensure all native form payloads are included.

3. Advanced Mode (Raw Request Override)

For highly obfuscated gateways that aggressively block DOM manipulation, enable the Raw Request Override in the Network tab. This bypasses the UI entirely and fires a direct HTTP packet.

Method: POST
URL: https://cp.gateway.local/login.php
Payload: escapeUser=admin&passwd=secret&ok=Login

Note: If the gateway utilizes dynamic CSRF tokens or single-use nonces generated on load, the raw payload may fail with a 503 or 401. In these environments, rely on the Standard DOM Parser.

4. Troubleshooting

If the extension fails to trigger automatically upon connecting to a new network, the OS may be isolating the portal. To force a trigger, manually navigate to a plaintext HTTP site:

http://neverssl.com
